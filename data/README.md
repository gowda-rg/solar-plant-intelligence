# Data directory

## Provenance policy

All files under `raw/` and `processed/` must document:

1. **Source** (URL, publisher, license)  
2. **Type:** `MEASURED` (public real data) or `SYNTHETIC` (generated for demo)  
3. **Time range and granularity**  
4. **Columns and units**  

Nothing in the application UI may present synthetic data as live plant SCADA without an explicit label.

## Current MVP data

| Label | Type | Origin |
|-------|------|--------|
| `SYNTHETIC_DEMO` | SYNTHETIC | Generated by `backend/scripts/seed_demo_data.py` — hourly points, daylight-shaped power curve, optional irradiance |

Replace or supplement with a cited public CSV in `data/raw/` when you add real measured data; keep `data_source` column honest in the database.

## Planned content

- `processed/` — cleaned exports aligned with ingest scripts
